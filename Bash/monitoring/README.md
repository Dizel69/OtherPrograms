# Мониторинг

` ping.sh ` - проверяет доступность сервера;

` host_ping_checker.sh ` - проверка доступности нескольких хостов с записью в лог;

` monitoring_cpu.sh ` - поиск процессов, которые потребляют >90% CPU;

` monitoring_mem.sh ` - поиск процессов, которые потребляют >60% ОЗУ;

` monitoring_cpu_and_mem.sh ` - поиск процессов, которые потребляют >90% CPU и >60% ОЗУ;

` resource_guardian.sh ` - скрипт автоматического обнаружения аномального потребления ресурсов в Linux;

` memory_spike_detector.sh ` - поиск процессов с высоким потреблением RAM;

` long_process_watcher.sh ` - поиск долго работающих процессов;

` inode_usage_monitor.sh ` - мониторинг использования inode на файловых системах;

` deleted_fd_monitor.sh ` - поиск открытых удалённых файлов (висящие дескрипторы);

` disk_space_allert.sh ` - скрипт по уведомлению на почту, если диск занят более чем на 90%;

` systemd_health_check.sh ` - проверка упавших systemd-сервисов;

` systemd_restart_analyzer.sh ` - анализ частых рестартов сервисов;

` update_monitor.sh ` - мониторинг обновления системы;

` xsession_monitor.sh ` - мониторинг входа в графическую систему;

` usb_state_monitor.sh ` - отслеживание изменений USB-устройств;
